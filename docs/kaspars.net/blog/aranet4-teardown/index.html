Aranet4 Teardown

January 25, 2020 Electronics, Home Automation 2 Comments

Aranet4 is a wireless CO2, temperature and relative humidity sensor with Bluetooth LE connectivity (made by SAF Tehnika) which is supported by the Sensor Pilot web app. It appears to be using the following components:

  • Rigado BMD-320 module (or BMD-30/35 after the u-blox acquisition) based on the Nordic nRF52832 chip with an ARM Cortex M4 CPU.
  • Senseair Sunrise NDIR CO2 sensor (by the looks of it).

Note that the Aranet4 PRO version has an additional LoRa radio which isn’t populated on this Aranet4 Home version.
